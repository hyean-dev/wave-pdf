# Wave PDF

휴대폰·PC·태블릿에서 쓰는 PDF 웹앱(PWA).

- 보기: 목차, 검색, 확대/축소(핀치), 암호 PDF 열기
- 주석: 하이라이트·밑줄·취소선(텍스트 선택), 펜, 마커, 지우개, 글상자, 메모, 도형, 서명
- 주석은 PDF 표준 주석으로 저장 → 다른 뷰어에서도 보이고, 다시 열면 편집 가능
- 페이지 편집: 회전, 삭제, 순서 변경, 빈 페이지, PDF 합치기, 페이지 추출
- 양식 채우기, 저장 시 암호 유지/설정
- 구글 드라이브 열기·덮어쓰기·새로 저장

사용 라이브러리: pdf.js (Apache-2.0), pdf-lib (MIT), fontkit (MIT), qpdf wasm (Apache-2.0), HarfBuzz (MIT), SortableJS (MIT), Pretendard (OFL), Lucide icons (ISC)
